# OM World collaboration restart

This restart focuses on maintaining the existing open protocol and reopening a clear path for technical review. The existing commit history, contributor attribution, licenses, and governance process are retained.

## Maintenance status — 2026-10-20

1. [PR #17](https://github.com/omworldprotocol/om-world/pull/17) and [PR #18](https://github.com/omworldprotocol/om-world/pull/18) were revised, reviewed for their bounded documentation scope, and merged. They add related-work citations with explicit evidence limits, not verified OM World adapters, deployments, or real-delivery results.
2. Identify outdated documentation and distinguish historical observations from currently verified behavior. Existing service endpoints have not been checked in this restart.
3. Align [contribution guidance](../CONTRIBUTING.md) and [roadmap status](../ROADMAP.md#status), and prepare proposals separating delivered drafts from unresolved issue scope. This maintenance does not close or change issues, initiate translation, contact contributors, publish announcements, or start experiments. Follow the existing governance process; no new response-time guarantee or contributor review commitment is introduced.

## Separate research subproject

[MSEC](https://github.com/omworldprotocol/msec) has been established as an independent public repository under the same organization, with separate scope, issues, history, attribution, and research decisions. Its initial repository contains project documentation only. Experiments, algorithm development, and publication of previous private research artifacts are outside this setup.

No prior OM World contributor is automatically a participant, reviewer, maintainer, or endorser of MSEC. New attribution must identify an actual contribution and respect the contributor's consent. Existing citation-only and non-endorsement boundaries remain in force.

## Licensing and history

The existing LICENSE, LICENSE-CODE, LICENSE-DOCS, contributor records, and copyright notices remain authoritative. Brand assets are outside the open code and documentation licenses. The restart does not replace historical governance or financial-policy statements.
