# OM World collaboration restart

This restart focuses on maintaining the existing open protocol and reopening a clear path for technical review. The existing commit history, contributor attribution, licenses, and governance process are retained.

## Initial maintenance scope

1. Review open pull requests #17 and #18 on their technical merits. This document makes no merge decision or review commitment on behalf of any contributor.
2. Identify outdated documentation and distinguish historical observations from currently verified behavior. Existing service endpoints have not been checked in this restart.
3. Use existing repository issues for documentation corrections and review suggestions. Follow CONTRIBUTING.md and the existing governance process; no new response-time guarantee is introduced.

## Separate research subproject

MSEC is proposed as an independent repository under the same organization, with separate scope, issues, history, attribution, and research decisions. Its initial repository contains project documentation only. Experiments, algorithm development, and publication of previous private research artifacts are outside this setup.

No prior OM World contributor is automatically a participant, reviewer, maintainer, or endorser of MSEC. New attribution must identify an actual contribution and respect the contributor's consent. Existing citation-only and non-endorsement boundaries remain in force.

## Licensing and history

The existing LICENSE, LICENSE-CODE, LICENSE-DOCS, contributor records, and copyright notices remain authoritative. Brand assets are outside the open code and documentation licenses. The restart does not replace historical governance or financial-policy statements.
